# Balloon Hangman

HTML/CSS/JavaScript version of the Balloon Hangman game.

## Project structure

- `index.html` — game page and HTML layout
- `css/style.css` — styling and animations
- `js/game.js` — game logic and interactions
- `assets/images/` — game images
- `assets/audio/` — game audio

## Note

The original HTML references:
`Heartbroken Yandere simulator theme.mp3`

Place that MP3 inside `assets/audio/` using the exact filename above if you want the loss music to work.
